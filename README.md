## 玩法
- 游戏主界面有3行5列的土地，左上角会显示当前拥有货币数量。你需要点击土地以种植作物，栽培作物，并卖掉成熟作物以赚钱。初始你有$5000，当货币数量达到$10000后，主界面右上角会始终显示一个奖杯。
- 可种植的作物：小麦（种植花费$100，卖掉获得$150）、水稻（种植花费$200，卖掉获得$300）。
- 栽培作物的方式：浇水、施肥。
- 允许铲除作物。
- 作物成熟条件：浇水次数不少于10次且施肥次数不少于5次。
- 可点击主界面左下角的博丽灵梦（“祈福”按钮）随机获得0~$100的货币，点击后冷却时间80秒。
- 可点击主界面右下角的东风谷早苗（“求雨”按钮）降雨，使现有全部作物浇水次数+1，点击后冷却时间40秒。
